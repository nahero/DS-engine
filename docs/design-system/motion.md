# Motion

Source: `tokens/motion.json`. Designed in code, not Figma, and kept in its own file so Figma re-exports never overwrite it.

## Tokens

| Token | Value | Use |
|---|---|---|
| `motion.duration.fast` | 100ms | Hover, focus, small state changes |
| `motion.duration.base` | 200ms | Enter/exit of popovers, toasts, row collapse |
| `motion.duration.slow` | 300ms | Side panel, large layout shifts |
| `motion.easing.standard` | `cubic-bezier(0.2, 0, 0, 1)` | Elements moving or changing on screen |
| `motion.easing.enter` | `cubic-bezier(0, 0, 0, 1)` | Elements appearing (decelerate) |
| `motion.easing.exit` | `cubic-bezier(0.3, 0, 1, 1)` | Elements leaving (accelerate) |

## Outputs

- **CSS:** `--ds-motion-duration-*`, `--ds-motion-easing-*` in `src/styles/tokens.css`.
- **JS:** `motion` in `src/styles/tokens.ts` (durations in seconds, easings as control-point arrays) for JS-driven animation.
- Both are generated by `npm run build:tokens`. CI fails if either drifts.

## Tailwind usage

| Need | Class |
|---|---|
| Duration | `duration-fast`, `duration-base`, `duration-slow` |
| Easing | `ease-standard`, `ease-enter`, `ease-exit` |
| Plain `transition` | Defaults to `duration.fast` + `easing.standard` |
| `animate-in` / `animate-out` (tw-animate, shadcn) | Default to `duration.base` + `easing.enter` / `easing.exit`; `duration-*` and `ease-*` override |

Tailwind's default easings (`ease-in`, `ease-out`, …) are removed. Numeric durations (`duration-150`) still compile but are hardcoded values; don't use them.

## Reduced motion

Under `prefers-reduced-motion: reduce`, every duration token becomes `0s`, so state changes are instant rather than removed. Anything using the tokens gets this for free. JS animation must check the preference itself, since `tokens.ts` values are static.

In Storybook, the **Motion** toolbar forces reduced motion (`[data-motion="reduced"]` on `<html>`). Preview every token in *Foundations/Tokens → Motion*.
